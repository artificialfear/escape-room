Soundboard

Give the game your own music and sound effects. Drag an audio file onto a slot (or click Choose file). If you leave a slot empty, the game keeps its built-in sound. mp3, m4a, ogg and wav files all work.

Changes take effect right away, even in a game tab that’s already open. Nothing here reveals any puzzles.

Where files are kept: files you add here are saved in this browser on this computer, so open the game from the same Chrome on the same Mac. To make a sound permanent and portable instead, upload it to the repo’s sounds/ folder named exactly like the slot ID (for example sounds/music_act1.mp3). If both exist, the file added here wins.
A few musical sounds are generated live because the game randomizes them each time, so they can’t be replaced.
