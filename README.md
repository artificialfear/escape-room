# The Last Recital

A two-player escape room played on a TV with phones as controllers. The game runs entirely in the browser and is hosted on GitHub Pages.

> **Players: don't read the code.** `js/game.js` and `HANDOFF.md` give away the puzzles.

## How to play

1. On the laptop, open **https://artificialfear.github.io/escape-room/**, click **Wake the house**, and cast the tab to the TV with Chrome's *Cast… → Cast tab*.
2. Click **Print the pages** and print the single sheet. Cut it into 4 cards. Don't hide them yet; the game will tell you when.
3. Each player scans the big QR code on the TV with their phone and picks their name.
4. Use the systems check on each phone (camera, microphone, TV sound). The checks don't reveal anything about the game.
5. When you're both ready, tap **We're ready**. From there the phones guide you.

You need: the laptop and both phones on the same Wi-Fi, the volume up on all devices, and about an hour. The phones' screens should stay on; if one sleeps, reopen the page and it reconnects.
