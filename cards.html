Printable pages

Print this single sheet, then cut out the four pages along their edges. Each page has a tab at the bottom saying who hides it. Don’t hide anything yet — the game tells each of you when, and you tear the tab off as you hide the page.

Print settings (Chrome): Scale 100% · Margins Default · open “More settings” and turn on Background graphics. Low on ink? Use Ink saver; the pages still work.
No printer? Write each tab’s code (the “No.” on each page) on a sticky note; you can type the code on your phone instead of scanning.
